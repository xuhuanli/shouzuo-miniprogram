# 饭团手作 · 微信小程序（云开发版）

「布艺缝纫手作 · 定制预约」小程序，8 个页面，顾客提交预约单进云数据库，店主在小程序内看单、推进度、填物流单号，顾客随时查看进度与单号。**不涉及线上支付。**

订单流转：`待确认 → 制作中 → 待发货 → 已发货 → 已完成`（待确认/制作中可取消）。
快递默认 **韵达快递**，另有顺丰、中通、圆通、申通、EMS、极兔、京东、德邦、百世、天天、其他。
运费规则：满 69 包邮，不满补 6r（在「确认预约」页自动算进参考价）。

## 双模式设计

同一套代码跑两种模式，靠 `config.js` 一个值切换：

| `config.js` 的 `envId` | 模式 | 表现 |
| --- | --- | --- |
| 空字符串 | 本地演示 | 订单存手机本地，换手机就看不到；商品用 `data/products.js` 里的示例 |
| 填了云环境 ID | 云端真实接单 | 订单/商品进云数据库，多设备同步，店主后台实时生效 |

没云环境也能完整跑通所有界面，方便先看效果；填上环境 ID 即刻变成真业务系统。

## 快速开始

1. 装「微信开发者工具」（稳定版）→ 导入本文件夹
2. **把 `project.config.json` 的 `appid` 换成真实 AppID**（`touristappid` 是游客模式，开不了云开发）
3. 顶部点「云开发」→ 开通 → 创建环境 → 复制环境 ID
4. 打开 `config.js`，把环境 ID 粘进 `envId`，把 `adminPass` 改成你自己的口令
5. 右键 `cloudfunctions/admin` →「上传并部署：云端安装依赖」
6. 云开发控制台建三个集合：`orders` / `products` / `shop`，按《云开发开通指南.md》配安全规则
7. 编译运行 →「关于小店」页最下方「店主入口」→ 输口令 →「导入示例作品」

详细图文步骤见工作区根目录的 **`云开发开通指南.md`**。

| 购物车 cart | 勾选 / 全选、改数量、单条删除；「管理」模式下全选批量删除；底部「合计 + 确定预约」，tabBar 带数量角标 |

| 我的 orders | 顾客自己的预约单：状态（待确认/制作中/待发货/已发货/已完成/已取消）、**物流单号（可复制）**、取消预约；底部有「关于小店」入口 |
| 关于 about | 店铺故事、四步工艺（你给的原文）、联系方式（微信 xx17687058 / 满 69 包邮 / 杭州发货）；最下方隐藏「店主入口」 |

## 数据层

`utils/db.js` 是唯一的数据出入口，顾客侧与店主侧分开：

- 顾客侧：`getProducts` / `getProduct` / `getShop` / `addOrder` / `myOrders` / `cancelMyOrder`
- 店主侧：`adminCall(action, payload)` → 全部走 `cloudfunctions/admin` 云函数，服务端校验口令

云函数支持的动作：`ping`（建集合）/ `listOrders` / `updateOrder` / `listProducts` / `saveProduct` / `removeProduct` / `initProducts` / `getShop` / `saveShop`

## 安全要点

- `products` / `shop` 安全规则设 `write: false`，只有云函数（管理员权限）能写，顾客改不了价格
- `orders` 设 `doc._openid == auth.openid`，顾客只能读写自己的单
- 管理口令校验在**云函数里**，前端拿不到、改不了
- 云端模式下顾客端隐藏「删除订单」，避免删单后店主丢记录

## 视觉

小清新粉 + 莫兰迪浅紫点缀，全站深棕文字。字体分工：

- **正文 / 按钮 / 表单**：站酷快乐体（`kuaile`）——笔画清楚，小字号也认得出来
- **店招 / 大标题 / 作品名 / 关于小铺**：沐瑶软笔手写体（`muyao`）——只在大字号用，手写味道

两套都免费商用，已子集化后 base64 内嵌在 `app.wxss`，无需网络加载。**新增了文案要重新子集化**，否则新字会掉回系统字体、看起来像「字体坏了」：用工作区根目录的 `rebuild_fonts.py`（它会把项目里所有 wxml/js/json 的字符收集进 `font-chars.txt`，再重新生成 `fonts/*.woff2` 并写回 `app.wxss` 与 `preview.html`），跑完还会打印缺字清单。

字号基准：正文 31rpx，店招 76rpx。传云开发后商品图走云存储，包体只会更小（当前约 1.1 MB / 2 MB）。
